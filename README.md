41. MATCH EXPLANATION

The system should display a concise explanation.

Example:

Excellent Match: Candidate's primary expertise and relevant experience closely match the requirement. The candidate also meets the required management level and salary range.

If there is a mismatch:

Key Gap: Candidate has the required GST experience but expected compensation is above the client's stated budget.

43. IMPORTANT PORTAL DESIGN PRINCIPLE

The user should not see a long questionnaire at one time.

Use a progressive flow.

Candidate

Profile → Primary Skills → Primary Experience → Secondary Skills → Secondary Experience → Management Level → Salary → Availability → Resume

Client

Company Profile → Management Level → Primary Skills → Primary Experience → Secondary Skills → Secondary Experience → Salary → Requirement Details

The user should be able to complete the profile in approximately 5–10 minutes.

44. MASTER MATCHING PHILOSOPHY

LedgerSkill should fundamentally answer four questions:

1. CAN THEY DO THE WORK?

Primary Skills

2. HAVE THEY DONE IT BEFORE?

Primary Relevant Experience

3. ARE THEY AT THE RIGHT LEVEL?

Management Level

4. ARE THEY WITHIN THE EXPECTED COMPENSATION?

Salary / Budget

Everything else helps refine the result.
